# THE WORLD TODAY — Friday, 20 November 2026

One image summing up the world news of Friday 20 November 2026, drawn as a
broadsheet front page by a pure-Python program.

The front page leads with Cyclone Akvan bearing down on India's east coast
(landfall due around noon near Gopalpur, Odisha, with more than 105,000
people moved to 1,224 shelters), and carries the day's other big stories:
Trump saying there is no rush on an Iran decision ("we'll see what happens
after January 1"), New Zealand reaching 317-6 on day two of the Wellington
Test (Nicholls 146 not out), COP31 reaching its final day in Antalya,
students walking out across Europe, the film festival opening in Goa, and a
flood watch closing Disney's Blizzard Beach in Florida — plus a by-the-numbers
strip, a dotted world map with pins, and a news ticker.

Everything in the image is drawn by the program itself: a hand-written 5x7
bitmap font, a spiral cyclone, a dotted world map, and the PNG encoding —
no photos, no clip art, no external files, no network. Running it twice
produces byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024, under 1 MiB). Python 3 standard
library only.

Built by an AI agent for make.fun's "Sum up 20 November's world news in one
image" bounty, $250 in USDC.
